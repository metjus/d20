# d20.sk

Slovenský web o Dungeons & Dragons: návody pre začiatočníkov, tvorba postavy, generátor príbehov a 3D kocky. SK/EN.

Statická stránka bez buildu: `index.html` + `logo.png`. Stačí nahrať obsah repozitára do koreňa webu (`public_html`).

Externé zdroje: Google Fonts a three.js r128 z cdnjs.

## Nasadenie cez cPanel (Git Version Control)

Súbor `.cpanel.yml` pri „Deploy HEAD Commit“ skopíruje `index.html` a `logo.png` do `~/public_html/`.
